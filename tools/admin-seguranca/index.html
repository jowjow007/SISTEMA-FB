Migração de segurança

Só para o administrador. Rode depois de publicar as novas regras do Firestore. Antes disso, pelo console, grave acesso = "ativo" no seu próprio cadastro, ou esta página não abre. Nas regras antigas, cada pessoa podia alterar o próprio cadastro, inclusive acesso e patrimonioVerTudo. Por isso esta página não confia nesses valores: a sugestão de acesso vem das abas, que só o admin libera. Cada gravação fica registrada em auditoriaSeguranca e no CSV.

1Acesso explícito

As novas regras só liberam dados para quem tem acesso = ativo. A sugestão repete quem tinha acesso pelas abas (admin ou alguma aba liberada). Um ⚠ indica alguém marcado como "ativo" sem abas, que pode ter gravado isso por conta própria nas regras antigas. Desmarque quem não deve continuar.

2Quem vê todo o patrimônio

Nas regras antigas, quem não tinha o campo via todo o patrimônio, e a própria pessoa podia gravar true no próprio cadastro. Por isso ninguém vem marcado: marque só quem deve ver tudo. Os demais veem os itens sob a própria responsabilidade. Quem cadastra patrimônio (permissão de Gestão) e os administradores veem tudo de qualquer forma.

3Robôs

O robô do Astrea só grava a agenda se a UID dele estiver em robos. A UID aparece no log do robô ("UID para robos/{uid}") e em Firebase Console › Authentication, na conta do robô.
