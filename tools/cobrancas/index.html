Relatório de Cobranças

Gere o relatório de débitos em aberto do cliente a partir da planilha de cobranças exportada do Asaas.

1. Dados das cobranças

No Asaas, abra Cobranças, filtre o cliente (ou a situação "Vencida") e use Exportar → Excel. O arquivo é lido só neste navegador; nada é enviado nem gravado no Portal.

Digite o nome do cliente e adicione os boletos um a um — competência, vencimento e valor original de cada um.

2. Cliente e boletos

Já vêm marcados os boletos não pagos vencidos até a data de referência. Desmarque o que não deve entrar ou marque parcelas a vencer para incluí-las sem encargos.

3. Encargos e dados do relatório

Mesma conta do Asaas para boletos vencidos: multa sobre o valor original e juros ao mês contados por dia (taxa mensal ÷ 30), com os centavos truncados. Com os percentuais configurados no Asaas, o valor bate com o boleto atualizado.

4. Pagamentos a abater

Se o cliente já pagou parte do débito, lance o pagamento aqui. O valor é descontado do total e aparece discriminado no fim da tabela do relatório.
